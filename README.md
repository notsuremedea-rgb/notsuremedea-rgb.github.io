# Cyber Goblin Studio

A small accessible project journal, hosted on GitHub Pages. Plain HTML and CSS, with no build step or third-party runtime dependencies.

## Update the site

- Edit index.html for the homepage and article cards.
- Copy an existing article page to start a new post; update its title, description, date and body.
- Link the new post from index.html.
- Put images in assets/ and include descriptive alt text.
- Use large readable text and keep evidence separate from hypotheses.
- Preview locally with a static HTTP server, check desktop/mobile layouts and links, then commit and push main.

GitHub Pages serves the repository root from main. Keep .nojekyll. No API keys, private logs or runtime profiles belong in this repository.
