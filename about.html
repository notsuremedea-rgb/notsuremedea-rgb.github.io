THE WORKSHOP · 14 NOVEMBER 2026

Useful things.
Honestly shared.

Cyber Goblin Studio is a home for the software, experiments and stories that grow out of trying to make technology work better.

Start with a real frustration

A crashing GPU. A screen that’s hard to read. A tool with too many tiny buttons. That’s the sort of problem that brings something onto this workbench.

We use AI coding tools to help turn ideas into working software, then inspect, test and improve what we build. The point is a useful result—and a clear account of what has and hasn’t been verified.

Make it readable

Large text, clear selected states and high-contrast controls matter here. Accessibility is part of the work from the beginning. This website uses system fonts, ordinary links and responsive pages without an animation framework or third-party tracking.

Show the limits alongside the results

One successful run isn’t proof of a permanent fix. We distinguish measurements, owner reports and hypotheses. Experiments stay labelled as experiments, and we welcome clear reports from other people trying compatible hardware.

What’s here now

  • Goblin Governor — a public, experimental NVIDIA GPU clock-control tool.
  • Clock-mode field notes — the first recorded experiment.
  • LightZoom — a private fullscreen magnifier build; not publicly released yet.

Join in

Found a problem with Goblin Governor? Use its GitHub issue template and include your model, driver, settings and what happened. Remove usernames, GPU identifiers and personal paths from anything you share.

There’s no mailing list or account to create here. New work will appear on the homepage as it’s ready.
